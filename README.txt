JENNY — PERSONAL TEACHING WEBSITE

Preview:
- Open index.html in a modern browser.
- The page uses Google Fonts from the internet.
- The portrait frame attempts to show the Google Drive file you provided. If it does not appear, change the Drive sharing permission to "Anyone with the link" or upload the photo directly into the project and replace the iframe with an img element.

Customize:
- Edit index.html to change copy, colors, email, links, and course details.
- All CSS and JavaScript are included in index.html.
- No build tools or package installation are required.

Deploy:
- Upload the folder to a static host such as Netlify, Vercel, or GitHub Pages.
